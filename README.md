# pipejson

Pipe identifiers and json tokens for idempotent workflows.

**Site:** https://theworker02.github.io/pipejson/

## Install / run

```bash
git clone https://github.com/theworker02/pipejson.git
cd pipejson
node src/cli.js
node --test
```
